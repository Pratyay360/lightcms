1. 🗂 Git-based Storage (No Lock-in)

All of your content lives in your own git repository. Each piece of content is automatically stored as a file with front matter. All your content will be versioned using Git, with no lock-in to a database. You can create different versions of your content using git branches, commits and pull-requests.

2. ✍ Easy-to-use editor with front matter

Using the powerful TipTap editor you can easily format your content with automatic clean markdown and front matter generation. You can use beautiful typography, math (KaTeX) and code highlighting, tables, task lists and drag-and-drop media.

3. 🤖 AI Writing Assistant

Use your integrated AI assistant to help you write and edit your content faster. Simply ask your assistant to help you with outlining your article, rewriting paragraphs, expanding on ideas and correcting grammar. You can use any OpenAI compatible AI provider (OpenAI, OpenRouter, Ollama cloud, NVIDIA NIM).

4. 🎙 Voice to text

Write your content as fast as you can think! Just speak into the editor and let OpenAI Whisper or Wit.ai convert it into text.

5. 🌗 Beautiful themes

Beautiful light and dark themes with full custom theme support.

6. 📬 Newsletter automation

We have built-in support for Newsy so any new posts will automatically be converted into newsletters and sent out to your audience. No monthly third-party newsletter subscriptions needed.

How does LightCMS work?

LightCMS hides away any complicated technical parts but provides some options to make it easier for you.

1. Log in to your LightCMS instance using your GitHub account.

2. Choose your GitHub repo that contains your static blog/website (Astro, Hugo, SvelteKit, Jekyll, Next.js, etc.).

3. Create/edit content. Easily create new articles or edit your posts with live formatting, media upload and front matter.

4. LightCMS will automatically create a commit/pull request to your selected branch.

5. Automatic deployment. LightCMS will integrate with your current build pipeline (cloudflare pages, netlify, vercel) to automatically deploy your site. If you want to do custom deployment,

Don’t worry, we have lots of example repos set up with CI pipelines to deploy to GitHub Pages.
