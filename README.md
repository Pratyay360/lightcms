# LightCMS

LightCMS is a git repository based content management system.
Specially meant to be used with static site generators like Hugo, 11ty,
Astro Starlight, Jekyll, etc.

techstack:

- Svelte-kit
- Octokit
- probot
- tiptap
- postgres
- better-auth
- drizzle-kit
